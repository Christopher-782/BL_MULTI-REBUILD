# BL Multi Concept — Full-Width Blue/Dark-Blue Login

This is a complete visual redesign of the login page.

## New layout

- 100vw × 100vh edge-to-edge desktop layout
- No centered container
- No white login background
- Dark navy operations side
- Royal blue authentication side
- Full-height split design
- Purpose-built responsive mobile layout

## Theme

Dark side:
- #06111f
- #08182d
- #0b2140

Blue side:
- #164cae
- #1555c0
- #0c3981
- #2d7ff9

## Preserved functionality

The working authentication logic is not rewritten.

Preserved IDs:
- loginForm
- email
- password
- togglePassword
- formMessage
- loginButton

The supplied `assets/js/auth/login.js` is copied unchanged from the working project.

## Dynamic UI

- Browser-local time updated every second
- Browser-local date
- Morning / afternoon / evening / late-night greeting
- Restrained animated chart
- Live status pulse
- Subtle dashboard pointer depth on desktop
- Reduced-motion support

## Install

Replace:
- login.html
- assets/css/auth.css
- assets/js/ui/login-ui.js

The included `assets/js/auth/login.js` is the unchanged working version for reference/safe overlay use.

No SQL migration is required.
