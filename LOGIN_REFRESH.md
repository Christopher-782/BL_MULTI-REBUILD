# Professional Dynamic Login Refresh

This patch changes ONLY the login experience.

It preserves these existing auth IDs so your current Supabase login JavaScript
continues to work:

- loginForm
- email
- password
- togglePassword
- formMessage
- loginButton

## Improvements

- Premium fintech split layout
- Real BL Multi Concept logo
- Dynamic good morning / afternoon / evening greeting
- Live local time and date
- Animated system-status indicators
- Subtle animated finance chart
- Subtle desktop pointer/parallax motion
- Professional input icons and focus states
- Better password control
- Responsive tablet/mobile layout
- Reduced-motion accessibility support
- No database or Supabase changes

## Installation

Copy these files over the current UI project:

- login.html
- assets/css/auth.css
- assets/js/ui/login-ui.js

No SQL migration is required.
